# ElementX ⚛️

### Engineering Intelligence for Chemical Elements & Materials

ElementX is an interactive web-based platform that helps users explore chemical elements through an engineering perspective.

Instead of simply displaying periodic-table information, ElementX connects element properties with **material selection, engineering applications, compounds, chemical reactions, and interactive learning**.

## 🚀 Features

### 🔬 Element Finder
Find suitable elements based on engineering requirements such as:
- High melting point
- Lightweight materials
- High conductivity
- High strength
- Corrosion resistance

### ⚖️ Compare Materials
Compare multiple elements side-by-side using properties such as:
- Atomic number
- Atomic mass
- Density
- Melting point
- Boiling point
- Electrical conductivity
- Valence

### 🧪 Compound Builder
Select two elements and explore commonly formed compounds and their applications.

### ⚡ Reaction Predictor
Select elements to explore possible chemical interactions and reactions.

### 🌀 Electron Visualizer
Visualize electron-related information for different elements.

### 🏭 Industry Uses
Explore how chemical elements are used across different industries and engineering applications.

### 🧠 Quiz Mode
Test your knowledge of chemical elements through an interactive quiz.

## 🎯 Project Objective

The goal of ElementX is to make chemical-element data more useful for engineering students and learners by connecting **chemistry with practical engineering applications**.
